# Дхарана — Android-приложение

Нативный проект Android на Kotlin + Jetpack Compose. Интерфейс на русском языке.

## Возможности версии 1.0
- Главный экран с ежедневной целью и временем практики за сегодня.
- Библиотека из шести упражнений: визуальная фиксация, дыхание, слуховое поле, переключение, открытое внимание, абстрактный объект.
- Экран практики с таймером, паузой, продолжением, выбором длительности и отметкой замеченных отвлечений.
- Сохранение завершённых сессий локально на устройстве.
- Экран статистики, история и настройка ежедневной цели.
- Работа без аккаунта и без интернет-разрешений.

## Сборка APK
1. Установить Android Studio (актуальную стабильную версию) и Android SDK Platform 35.
2. Открыть папку `DharanaAndroid` в Android Studio.
3. Дождаться Gradle Sync.
4. Выбрать **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется JDK 17. Минимальная версия Android — 8.0 (API 26).

## Примечания
Это первая полноценная рабочая основа приложения, а не медицинский инструмент и не измеритель сознания. Счётчик отвлечений основан на самостоятельных отметках пользователя. Визуальная фиксация не требует смотреть на экран непрерывно: при усталости глаз следует закрыть практику и отдохнуть.

## Автоматическая облачная сборка APK через GitHub

В проект добавлен workflow `.github/workflows/build-apk.yml`.

1. Создайте аккаунт на https://github.com/ и новый репозиторий (например, `DharanaAndroid`).
2. Загрузите в репозиторий всё содержимое папки `DharanaAndroid` (включая скрытую папку `.github`). Это можно сделать через GitHub в браузере: **Add file → Upload files**.
3. Откройте вкладку **Actions** репозитория. Если GitHub попросит разрешить Actions, подтвердите.
4. Выберите workflow **Build Android APK** и нажмите **Run workflow**. Если workflow не появился, убедитесь, что файл `.github/workflows/build-apk.yml` загружен в ветку `main` или `master`.
5. Дождитесь зелёной отметки успешной сборки.
6. Откройте завершённый запуск workflow. Внизу страницы в разделе **Artifacts** скачайте `Dharana-debug-apk`.
7. Распакуйте скачанный архив и установите `app-debug.apk` на Android.

APK собирается на серверах GitHub Actions. Для этой сборки не нужны Android Studio или компьютер с Android SDK у пользователя. Первый запуск сборки может занять несколько минут.
